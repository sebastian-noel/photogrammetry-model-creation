# Photogrammetry Model Creation
UCF Institute for Simulation & Training (IST) | METIL Sim Jam Internship Project #5

### Team: Sebastian Noel, Stevin George, Gavin Heaver

### Project Description:
Using RealityScan to create riggable 3D models with high detail for Unity developed VR applications.

### Pipeline:
Taking multiple photos of objects from different angles to construct a 3D model, rig the model for basic functionality, and then importing that model into Unity.
