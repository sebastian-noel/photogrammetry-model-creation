# Project #5 — Photogrammetry Model Creation

## Project Point of Contact

- Lauren Speer (KCNSC)

## Tech Stack

- **Software/languages:**
  - Unity
  - RealityScan (preferred, but not required — MUST be desktop-based)
- **Hardware:**
  - DSLR/mirrorless camera

## Goals

This project will test an on-premise photogrammetry software (RealityScan preference) to create riggable 3D models that are realistic enough for Unity developed VR applications. Models should vary in size - small = pack of gum, medium = shoe box, large = computer desk. The project should illustrate the pipeline to take the photos of multiple objects, convert the photos into a 3D model, rig the model for basic functionality, and import into Unity.

- Pipeline to import photogrammetry models into Unity
- Models to be 'riggable' to open doors, turn knobs, etc
- Documentation on proper photography (lighting, distance, distortion, resolution, etc), methodology to rig models, method to import into Unity

## IP Restrictions/Special Considerations

Other photogrammetry options are viable but cannot be cloud, phones can be used for images but not processing, cannot use phone LiDAR or other sensor suites
